# 에뮬레이터 확인표(장면 ①, ②)

상태: 단위 테스트, 빌드까지 검증됨. 아래 항목은 모두 미검증이다. 개발 노트북 GPU(Intel Arc 내장)가 Pleos Connect Emulator 사양에 못 미쳐 에뮬레이터를 실행할 환경이 없다.
준비: 앱 설치 → `"$ADB" forward tcp:8088 tcp:8088` → http://127.0.0.1:8088/ (Virtual Console). 카드, 값 이름은 Virtual Console 화면에서 실제 이름으로 고쳐 적는다.

앱이 다루는 값(운전석 `SeatArea(ROW_1_LEFT)` 기준): 공조 전원, 설정 온도(°C), 풍량, 시트 열선, 시트 통풍. 출처는 `app/src/main/java/app/myvision/data/PleosVehicleGateway.kt` 주석.

| # | Virtual Console 카드 | 바꿀 값 | 앱이 해야 할 일 | 확인 |
|---|---|---|---|---|
| 1 | 기어 | P | 화면에 "지금 상태를 이 프로필로 저장" 버튼이 보인다 | 미검증(에뮬레이터 환경 없음) |
| 2 | 공조, 시트 | 온도 22, 풍량 3, 전원 켜짐, 열선 2, 통풍 0 → 앱에서 "아빠" 선택 → 저장 | "지금 시트와 공조를 저장했어요." | 미검증(에뮬레이터 환경 없음) |

## 장면 ② 단속 카메라 사전 안내

내비 모의 주행, 카메라 이벤트 주입 방법은 Pleos 문서에서 찾지 못했다(미정). 아래는 경로 안내 중 카메라 이벤트가 온다는 전제의 확인 항목이다. 규칙 출처는 `app/src/main/java/app/myvision/alert/CameraAlertPlanner.kt`.

| # | 상황 | 앱이 해야 할 일 | 확인 |
|---|---|---|---|
| 12 | 운전자 "아빠"(기본), 지점 단속 카메라 500m 이내 진입 | 음성 "500m 앞 단속 카메라, 제한 N." 한 번. 화면이 제한속도 + 남은 거리로 바뀐다 | 미검증(에뮬레이터 환경 없음) |
| 13 | 12번 뒤 같은 카메라로 계속 접근 | 다시 말하지 않는다. 남은 거리 숫자만 줄어든다 | 미검증(에뮬레이터 환경 없음) |
| 14 | 운전자 "나"(자주 놓침), 같은 카메라 | 1000, 500, 200m 앞에서 세 번 말한다 | 미검증(에뮬레이터 환경 없음) |
| 15 | 안내 뒤 제한속도 초과 | "제한 속도를 넘었어요. 속도를 줄여요." 기본 1회, 자주 놓침 2회까지 | 미검증(에뮬레이터 환경 없음) |
| 16 | 구간단속 안에서 구간 평균속도 초과 | "구간 평균 속도가 제한을 넘었어요. 평균 N, 제한 M." 화면은 제한속도 + 구간 평균속도 | 미검증(에뮬레이터 환경 없음) |
| 17 | 카메라를 지남 | 운전자 선택 화면으로 돌아온다(빈 목록이 온다는 추정. 안 오면 패널이 남는다) | 미검증(에뮬레이터 환경 없음) |
| 18 | 값 확인 | `speedLimit`, `sectionAvrSpeed`가 km/h, `remainDistance`가 m인지, `status`와 `CameraType`의 뜻(추정) | 미검증(에뮬레이터 환경 없음) |

## 구현에서 뺀 것과 이유
- 시트 위치(앞뒤), 등받이: Vehicle SDK 2.3.2는 `moveSeatForeAft(MoveControl.FORWARD/BACKWARD/STOP)` 같은 이동 명령만 있고 목표 값 쓰기가 없다. 이동, 정지 제어는 에뮬레이터 확인 없이 넣지 않았다.
- 미러: `SideMirror` API는 있으나 Virtual Console 지원 미확인이라 뺐다.
- 기어, 주행 가능 거리 API는 SDK에서 deprecated(Google `GEAR_SELECTION`, `RANGE_REMAINING` property를 쓰라고 안내). 8, 1번에서 값이 안 오면 교체한다.
