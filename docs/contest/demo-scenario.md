# 3분 시연 시나리오

에뮬레이터: Pleos Connect Emulator 2.1.0(API 34). 조작: Virtual Console(http://127.0.0.1:8088/). 구간 시간은 초안이며 리허설 후 고친다.

| 시각 | 장면 | 심사위원이 보는 것 | 조작 | 상태 |
|---|---|---|---|---|
| 0:00~0:20 | 문제 | 차를 함께 쓰면 설정이 매번 바뀌고, 주행 중 놓치는 정보가 있다 | 발표 | 계획만 |
| 0:20~1:20 | ① 운전자 전환 | 운전자 B 탑승 → 시트, 공조가 B 설정으로 복원, 음성 한 줄 | Virtual Console로 시트, 공조를 A 값에 두고 앱에서 B 타일 선택(프로필 선택 방식, [emulator-check.md](emulator-check.md)) | 구현 보고(에뮬레이터 미확인) |
| 1:20~2:30 | ② 단속 카메라 선안내 | 카메라 접근 → 음성 선안내 → 화면에 정보 1~2개만 | 카메라 이벤트 주는 방법 미정(내비 모의 주행 방법이 문서에 없음) | 계획만 |
| 2:30~3:00 | 구조 | 규칙 엔진 표(입력 → 단계), 테스트, CI | 슬라이드 | 계획만 |

## 미정, 위험
- 카메라 이벤트를 에뮬레이터에서 일으키는 방법(NaviHelper 모의 주행 지원 여부). 안 되면 대체 방법과 그 사실을 화면에 "예시 입력"으로 밝힌다.
- 운전자 인식: 프로필 타일 선택으로 결정(음성 인식은 범위 밖).
